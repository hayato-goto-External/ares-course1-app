# ARES Course1 過去問アプリ

不動産証券化協会認定マスター Course1 の過去問学習アプリ（PWA）。
500問（2021〜2025年度・5年分）を収録し、iPhone のホーム画面から起動可能。

## 主な機能

- **通常演習**：年度・科目・出題項目・形式でフィルタして解く
- **今日の10問**：ランダム10問（習慣化用）
- **苦手集中**：正答率60%未満の項目を自動抽出
- **本試験モード**：50問120分のタイマー付きシミュレーション
- **ブックマーク**：気になる問題を保存
- **統計**：科目別正答率、苦手項目、7日間の学習履歴
- **間隔反復（SRS）**：解いた問題を「もう一度／難しい／普通／簡単」で評価すると、次回復習日が自動計算される（Anki風）
- **メモ機能**：問題ごとに自分の解説メモを追加
- **オフライン動作**：一度読み込めばオフラインで完全動作
- **ダーク／ライトモード**：システム設定に自動追従
- **エクスポート／インポート**：学習履歴を JSON でバックアップ

## デプロイ手順

### オプション1：GitHub Pages（推奨・無料）

1. GitHubに新規リポジトリを作成（例：`ares-course1-app`）
2. このフォルダ内の全ファイル（`index.html`, `app.js`, `styles.css`, `data.js`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`）をリポジトリに push
3. リポジトリの Settings → Pages → Source を「main」ブランチのルートに設定
4. 数分後、`https://<ユーザー名>.github.io/ares-course1-app/` でアクセス可能

### オプション2：Vercel / Netlify（無料）

1. [Vercel](https://vercel.com) または [Netlify](https://netlify.com) で無料アカウント作成
2. このフォルダをドラッグ&ドロップでデプロイ
3. 発行された URL でアクセス

### オプション3：ローカルで動作確認

```bash
cd ares-app
python3 -m http.server 8000
# ブラウザで http://localhost:8000 にアクセス
```

**注意**：`file://` プロトコル（HTMLファイルを直接ダブルクリック）だと Service Worker が動作せず、PWA として使えません。必ず HTTP/HTTPS サーバーから配信してください。

## iPhoneホーム画面に追加

1. Safariで公開URLを開く
2. 共有ボタン → 「ホーム画面に追加」
3. アイコンがホーム画面に追加され、フルスクリーンで起動可能に

## 収録データの内訳

| 年度 | 問題文＋選択肢 | 正答 | 出題項目タグ | 解説 |
|---|---|---|---|---|
| 2021 | ✓ | ✓ | — | — |
| 2022 | ✓ | ✓ | ✓ | ✓ |
| 2023 | ✓ | ✓ | — | — |
| 2024 | ✓ | ✓ | ✓ | ✓（全100問）|
| 2025 | ✓ | ✓ | ✓ | ✓ |

- 特に **2024年度は全100問に解説あり**
- 新カリキュラム（2024・2025）の200問はメタデータ完備

## SRS（間隔反復）アルゴリズム

Anki の SM-2 を簡略化した方式：

| 評価 | 意味 | 次回復習 |
|---|---|---|
| もう一度 | 間違えた／わからない | 1日後 |
| 難しい | 正解したがギリギリ | 3日後（以降 ease × 1.5） |
| 普通 | 普通に正解 | 7日後（以降 ease × 2.0） |
| 簡単 | 楽勝 | 14日後（以降 ease × 2.5） |

「もう一度」を選ぶと ease が下がって、次回以降の間隔も短くなります。

## データはブラウザに保存

すべての学習履歴・メモ・ブックマーク・SRS状態は端末のブラウザの localStorage に保存されます。
- サーバーには送信されません
- 端末が変わったら「エクスポート」→ 新端末で「インポート」で移行可能
- Safari のプライベートブラウズでは動作しません（通常モードで使ってください）

## トラブルシューティング

**Q: PWA として動作しない**
- HTTPS で配信されているか確認（GitHub Pages / Vercel は自動で HTTPS）
- ブラウザで一度ページを開いてから「ホーム画面に追加」
- iOS 16.4 以降を推奨

**Q: 進捗が消えた**
- Safari の「サイトデータをクリア」を実行していませんか？
- 設定 → データ管理 → エクスポート で定期バックアップを推奨

**Q: 解説が「収録されていません」と表示される**
- 2021・2023年度は解説PDFの技術的制約により未収録です
- 該当年度の解説を確認したい場合は、公式解答解説PDFを参照してください
